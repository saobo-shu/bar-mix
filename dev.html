两个容易漏掉的按钮（很多人不知道它们能点）
杯子里的每一样材料，名字后面都有两个小标签，它们都是按钮：
  • 「常温」＝ 温度。点一下在 冷冻 -18℃ → 冷藏 5℃ → 常温 25℃ 之间轮换，点满一圈回到默认。 同一瓶可乐，从冰箱拿还是从货架拿，能把杯子里的冰化出好几倍的水——这一步直接决定你这杯最后有多浓。 摇和、搅拌的也一样：材料越凉，摇壶里的冰化得越少，加进去的水就越少。 烈酒向的酒（马天尼、古典）尤其明显：酒吧会把基酒整瓶放冷冻室，同样搅二十秒，加进去的水少一半——结构分里也算这一条。 热水这类材料只在「热 / 常温」之间换；装饰（柠檬皮、薄荷叶）和按滴算的苦精不占体积，所以没有温度标签。
  • 「40%」＝ 酒精度。点一下改成你瓶子上印的数字。同一款酒各国版本度数不一样 （哥顿 37.5 / 40、添加利 47.3、美格 46 是产品名不是度数），算浓度和评分都按你填的算。
  • 填错、填乱码都没关系——留空或填 0 就恢复成默认度数。
四个开关（都在「① 杯子里」）
  • 口味（清淡 / 标准 / 浓烈）：决定"多少度才算正好"。它只管浓度这一项，不影响别的。
  • 冰量（满冰 / 半杯冰 / 不加冰）：决定能倒多少液体、以及冰能化出多少水。
  • 做法（兑和 Build / 搅拌 Stir / 摇和 Shake）：决定准备时加多少水——兑和不加水，搅拌约 20%，摇和约 25%。
  • 评分（五套权重方案）：不管选哪套，平衡度永远是权重最大的那一项。
不想一样样挑？两条捷径
  • ④ 经典配方 里点一张卡片：材料、杯型、冰量、做法、口味会一起装好，就像有人替你摆好了—— 点干马天尼会自动切到「浓烈」，因为它 35 度，本来就不该用「标准」去量。改两下就是你的版本。
  • 点右上角 「换基酒」：把配方里写的酒换成你手上那瓶，比例不用重算。
怎么读结果
  • 分数只是参考。真正有用的是下面三块：风味图（这杯是什么味道）、「冰化开会怎么样」（会变多淡）、「怎么再调一步」（下一步加什么）。
  • 杯子里只有一样酒（比如纯饮一杯威士忌）时不评分，只描述味道——"这杯好不好"不是这个工具能回答的。
  • 杯子装不下只是提醒，不扣分：你手上那只杯子可能比标称的大，自己判断。
  • 手机上可以「添加到主屏幕」，打开是全屏、没地址栏，断网也能用。
  • 这个页面用百度统计看匿名访问量（多少人来了、从哪来、用什么设备）。你调了什么酒、放了哪些材料都不会被记录——那些只在你自己的浏览器里算。

    冰从哪来（这件事比买什么酒重要）
    冰占了调酒的一半。同一瓶酒，加不加冰完全是两种东西。
    • 便利店：夏天的冰杯，两三块钱一个，直接是杯子形状，倒进去就能用。
    • 超市：袋装冰块、泡沫保温箱、冰袋（家用区，几十块）。
    • 做法：买一袋冰 + 两块冰袋，一起丢进泡沫箱，盖上盖，能撑一晚上。喝之前再拿出来，别一直开着盖。
    • 想更讲究：网购硅胶大方冰模具，但没冰箱冻不了，可以不买。
    一颗柠檬用不完怎么办（住处最常见的浪费）
    一颗中等柠檬大约出 40ml 汁，一杯威士忌酸用 20ml——所以一颗柠檬 = 两杯。买之前先决定今天做几杯，或者干脆一次挤完。
    • 别挤一半留一半。切开的柠檬接触空气会氧化发苦，表面还容易长霉。这是最容易被忽略的一步。
    • 一次挤完，做成柠檬糖浆：汁 + 等量白砂糖搅到化开，装瓶常温能放 2-3 周。用它的时候 30ml 就顶掉「20ml 柠檬汁 + 15ml 糖浆」，配方反而更简单。
    • 皮别扔，做糖渍柠檬皮：皮切条拌白糖腌 6-12 小时，糖会把皮里的香油逼出来，滤掉皮就是香气最浓的糖浆，常温放一个月。等于用废物升级了整杯酒的香气。
    • 真的只剩半颗：切面朝下扣在小碟子上，外面裹紧保鲜膜，放阴凉处能撑 2-3 天。裸露着放半天就干了。
    • 不想折腾就用瓶装柠檬汁：便利店就有，开封后常温能放一个月左右，代价是香气比现挤的闷一点。够用，但别指望它撑起一杯高级的酒。
    糖浆能常温放多久（莫林这类）
    糖浆的保质期取决于糖度——糖多水少，水活度低，细菌就长不起来。
    • 莫林这类商业糖浆：未开封常温 2-3 年（看瓶身）。开瓶后阴凉避光，纯糖浆（香草、焦糖、榛子）放半年到一年没问题，只是香气会慢慢变淡；果味、含果肉的品种建议 3-6 个月内用完。住处里买 250ml 小瓶比 700ml 实际得多。
    • 自制 1:1 糖浆：常温 2-3 周。
    • 自制 2:1 糖浆（富糖浆）：糖多水少，常温能放半年以上。住处首选这个，甜度按 2/3 折算就行。
    • 加一勺伏特加（约糖浆体积的 10%）：能把常温保质期再拉长几个月，味道几乎尝不出来，是酒吧的常规做法。
    • 真正让它坏的是污染，不是时间：别把沾过酒或水的勺子伸进瓶里，别兑水，用倒酒嘴最干净。很多"糖浆坏了"其实是长霉。
    • 蜂蜜不用管，常温几乎不坏。
    柠檬汁到底买什么（新的 Sunquick 能不能用）
    按「调酒效果」和「住处可操作性」两个维度排，四个选项：
    • ① 新鲜柠檬 — 效果最好。香气是唯一且无法替代的，皮油更是瓶装货给不了的。一颗约 40ml，正好两杯。麻烦点在于要现挤、要处理剩下的半颗。
    • ② 瓶装纯柠檬汁（宝蓝吉 / 如实 / ReaLemon 这类，超市或便利店）— 日常够用。开封后常温约 1 个月。做威士忌酸完全成立，只是香气闷一点。忙的时候用它，不忙的时候现挤。
    • ③ 柠檬糖浆（整颗柠檬一次挤完 + 等量糖）— 住处最优解。一次解决"剩下半颗"的问题，常温放 2-3 周，而且它本身就是酸+甜，30ml 顶掉「20ml 柠檬汁 + 15ml 糖浆」。
    • ④ 新的（Sunquick）浓缩柠檬 — 能用，但它不是柠檬汁。它是丹麦可罗（CO-RO）的含糖浓缩水果饮料，官网原话是"由真正的柠檬汁制成"，但要兑水才当饮料喝。也就是说它酸和甜都带着，还有一点饮料感。
      用法：把它当「酸 + 甜」二合一，用它就把糖浆减掉；适合做长饮（配苏打水、茶、可乐），不适合做需要精确酸甜的经典配方。直接 30ml 浓缩 + 45ml 威士忌 + 120ml 苏打水就能出一杯很稳的柠檬高球。
      优点：常温能放 3-6 个月（高糖浓缩，开封后也耐放），是这四个里最不用操心保存的。
    结论：想做正经鸡尾酒 → 买新鲜柠檬，用不完就做成柠檬糖浆；只想在住处随手调个柠檬味微醺、又不想管保存 → 新的完全可以用，只要记得它不是酸，是「酸甜饮料」。
    一杯酒的通吃公式：45 / 20 / 15
    烈酒 45ml ＋ 酸（柠檬汁）20ml ＋ 甜（糖浆）15ml，再加冰，最后兑 90-120ml 气泡水。
    • 想更烈 → 少放气泡水。想更顺 → 加冰、加气泡。
    • 想更香 → 一条橙皮（在杯口拧一下喷皮油）＋ 2 滴苦精。
    • 太甜了就加酸，太酸了就加糖，一次只加 5ml，别一步到位。
    • 这套公式换上金酒、朗姆、伏特加照样成立。以后基酒换着买，配方不用重学。
    为什么会结块（pH 和蛋白酶，两件事）
    加了奶的酒起絮，有两个完全不同的原因，混在一起想就会搞错：
    • ① 酸把 pH 压得太低。牛奶蛋白在 pH 低于 5 左右开始析出。柠檬汁 pH 只有 2.2，所以在 100ml 牛奶里加 10ml 柠檬就足以让整杯起絮。杯子面板上那个「预估 pH」就是干这个用的——低于 5.0 而且有奶，右边会直接警告你。
    • ② 蛋白酶，跟 pH 完全无关。菠萝里的菠萝蛋白酶、生姜里的生姜蛋白酶、木瓜、猕猴桃、无花果都有。它们会把奶类蛋白和椰浆的乳化结构直接拆开——所以椰林飘香（菠萝汁 + 椰浆）倒下去那一刻就可能分层，而它的 pH 其实不算极低。加酒会加快这个过程。
    • 常见误判：养乐多、可尔必思喝起来很酸，但它们本身就是稳定发酵体系，加柠檬、加奶都没问题。判断标准不是"酸不酸"，是 pH 和有没有酶。
    • 救法：菠萝汁煮开一分钟把酶灭活、放凉再用；或者直接买罐装 / 超高温灭菌的果汁，工厂已经灭过酶了。这也是为什么酒吧的椰林飘香能稳定出品，而家里用鲜榨菠萝汁经常翻车。
    没冰箱，什么能囤、什么别碰（风险清单）
    材料库里的「放心买 / 注意 / 高风险」就是按这张表来的。判断标准只有一个：买到手之后，在没冰箱的住处里它有多难伺候。
    • 放心买（常温久放）：所有基酒（开封后 40 度左右的烈酒能放 1-2 年）、苦精（几乎永久）、干香料、蜂蜜、白砂糖、未开封的罐装饮料、茶、挂耳咖啡。
    • 要注意（开封后有时间压力）：自制糖浆 2-3 周、莫林糖浆开封后 3-12 个月、红石榴糖浆 3-6 个月、瓶装柠檬汁 1 个月、生姜 1-2 周、阿佩罗 1-2 个月。
    • ⚠️ 高风险（一买就必须马上安排用完）：
      • 味美思、干味美思、利莱白 — 开瓶后必须冷藏，2-4 周内用完。没冰箱就别买大瓶，这是最容易翻车的一样。想做罗伯罗伊就买 375ml，一次叫上室友喝完。
      • 百利甜、牛奶、淡奶油、椰浆 — 含奶，开瓶后必须冷藏。住处只适合"买一次喝一次"，不适合常备。
      • 鲜榨柠檬/青柠汁、切开的水果、蛋清 — 当天用完，没有例外。
      • 开封的果汁 — 冷藏 2-3 天，住处买小盒装。
      • 气泡酒 / 香槟 — 开瓶后当天喝完，气泡跑了就只剩酸水。
    • 整颗柠檬、青柠、橙子在阴凉处能放 3-5 天，比切开的耐放得多——所以买整颗，别买切好的。
    • 一个实用原则：高风险材料尽量用"一顿能喝完的最小包装"。买不到小包装，就约人一起喝，或者干脆换配方。
    • 没有冰箱也能用温度：一瓶 40 度的基酒放冷冻室不会冻上（酒吧本来就这么存），倒出来几乎不化冰；饮料在便利店买的时候本来就是冷的，拎回来就用。同一杯金汤力，材料全放常温会被冰化出 40ml 水，冷冻加冷藏只需要 0-2ml。杯子里每样材料上的温度标签点一下就能改（冷冻 -18℃ / 冷藏 5℃ / 常温 25℃）。
    添置清单（大概 100 块，网购）
    • 量酒器 / jigger：最重要的工具，9 块左右。凭感觉倒的酒，九成是错的。
    • 摇酒器：住处空间小，直接买一个 500ml 的密封保温杯当摇酒壶也行，盖紧摇 15 秒效果差不多。
    • 吧勺 + 滤冰器：不贵，提升很大。
    • 杯子：一个厚直身的高球杯 + 一个古典杯（矮的厚底杯），基本什么都能做。
    • 泡沫保温箱 + 冰袋：解决没有冰箱的问题。
    三条铁律
    • 顺序：冰先放 → 酒 → 酸和甜 → 气泡水最后，只提两下，别搅散气泡。
    • 先少后多：糖和酸都一点点加，味道是加出来的，不是减出来的。
    • 立刻洗：糖浆和果汁干了以后粘在量酒器上很难洗，喝完冲一下，十秒钟的事。
